# 构建与测试指南

**版本**: v1.1.0-beta  
**适用环境**: Windows 10/11 + .NET 8.0 SDK

---

## 1. 先决条件

### 1.1 必须安装

| 工具 | 版本要求 | 获取方式 |
|:---|:---|:---|
| .NET SDK | 8.0.x | https://dotnet.microsoft.com/download/dotnet/8.0 |
| AutoCAD | 2018 或更高版本 | 正版授权安装 |
| Git | 任意版本 | https://git-scm.com |

验证安装：
```bash
dotnet --version   # 应输出 8.0.x
```

### 1.2 AutoCAD 依赖 DLL

项目编译依赖三个 AutoCAD 托管库，**不随仓库分发，需从本机 AutoCAD 安装目录手动复制**。

**合规说明**：这三个 DLL 是 Autodesk AutoCAD 的组成部分，受 Autodesk EULA 约束，不得公开分发或提交到公开仓库。对外分发时请确保它们不进入公开仓库，`build/References/` 下应只保留说明文档。

| 文件 | 来源路径（AutoCAD 2024 示例） |
|:---|:---|
| `acdbmgd.dll` | `C:\Program Files\Autodesk\AutoCAD 2024\` |
| `acmgd.dll` | `C:\Program Files\Autodesk\AutoCAD 2024\` |
| `accoremgd.dll` | `C:\Program Files\Autodesk\AutoCAD 2024\` |

复制到仓库目录：
```
MetroDesignToolKits/build/References/
├── acdbmgd.dll      ← 从 AutoCAD 安装目录复制，不提交 git
├── acmgd.dll        ← 同上
├── accoremgd.dll    ← 同上
└── README.md        ← 说明文档（已提交）
```

> **注意**：这三个 DLL 仅用于编译，不随插件一起发布。

## 2. 标准命令集

### 2.1 还原依赖

```bash
dotnet restore MetroDesignToolKits/MetroToolKits.sln
```

### 2.2 编译

```bash
# Debug（开发用）
dotnet build MetroDesignToolKits/MetroToolKits.sln

# Release（发布用）
dotnet build MetroDesignToolKits/MetroToolKits.sln -c Release
```

预期输出：`0 个错误`（警告来自 AutoCAD DLL 版本兼容性，可忽略）

### 2.3 运行单元测试

```bash
# 运行所有可脱离 AutoCAD 的单元测试
dotnet test MetroDesignToolKits/MetroToolKits.sln --filter "FullyQualifiedName~MetroToolKits.Tests"

# 单独运行 Foundation 层测试
dotnet test MetroDesignToolKits/src/Tests/MetroToolKits.Tests.Foundation/

# 单独运行 Core 层测试
dotnet test MetroDesignToolKits/src/Tests/MetroToolKits.Tests.SectionGenerator.Core/
```

预期输出：阶段五基线为 `100 个测试，0 个失败`；阶段六至阶段七已补充回归测试，待在可恢复 NuGet 的环境中更新最新统计。

### 2.4 发布（打包插件）

```bash
dotnet publish MetroDesignToolKits/src/Plugins/SectionGenerator/MetroToolKits.SectionGenerator.Plugin/ \
  -c Release \
  -o ./publish/SectionGenerator
```

发布目录将包含 `MetroToolKits.Bootstrap.dll`、插件依赖 DLL、`Microsoft.Extensions.*.dll`、`SectionGeneratorConfig.json`、`ElementTypes.json` 与 `README-release.md`。

### 2.5 AutoCAD 宿主烟测

```powershell
.\build\host-smoke-test.ps1 `
  -AcadConsolePath "C:\Program Files\Autodesk\AutoCAD 2025\accoreconsole.exe"
```

预期输出：

```text
宿主烟测通过：SectionSelfTest 返回 OK
```

该脚本会执行最小宿主闭环：

1. `NETLOAD MetroToolKits.Bootstrap.dll`
2. 执行 `SectionSelfTest`
3. 校验 `Bootstrap`、命令桥接、DI 和关键服务解析是否成功

## 5. CI 说明

仓库配置了 GitHub Actions（`.github/workflows/ci.yml`），在每次 push 和 PR 时自动执行：

1. 还原 NuGet 依赖
2. 编译解决方案（Debug）
3. 运行所有单元测试（阶段五基线 100，后续回归测试按最新统计）

> **注意**：CI 环境没有 AutoCAD，因此只运行不依赖 AutoCAD 的单元测试。集成测试需在本地 AutoCAD 环境中手动执行。

## 6. 常见问题

**Q: 编译报错 "找不到 acdbmgd"**  
A: 检查 `build/References/` 目录是否有三个 AutoCAD DLL，参考第 1.2 节。

**Q: 测试报错 "找不到 net8.0-windows"**  
A: 确认安装了 .NET 8.0 SDK，且系统为 Windows。

**Q: 插件加载后命令不可用**  
A: 标准入口是 `NETLOAD MetroToolKits.Bootstrap.dll`。另外确认 `MetroToolKits.Bootstrap.dll`、`MetroToolKits.SectionGenerator.Plugin.dll`、`Microsoft.Extensions.*.dll`、`SectionGeneratorConfig.json` 与 `ElementTypes.json` 位于同一目录。
