## 开发日志结构化规范文档

以下为 `MetroToolKits` 项目开发阶段日志的结构化说明，涵盖日志级别定义、各模块日志记录点、配置切换机制及实施建议。

---

### 1. 日志级别定义

| 级别 | 用途 | 生产环境默认 | 开发环境默认 |
|:---|:---|:---:|:---:|
| `Trace` | 极详细的算法步骤（如每个构件剖切坐标、每层图层遍历详情） | ❌ 关闭 | ✅ 开启 |
| `Debug` | 开发调试信息（如构件数量、配置加载路径、耗时统计） | ❌ 关闭 | ✅ 开启 |
| `Information` | 关键操作记录（命令执行开始/完成、文件读写、剖面生成结果） | ✅ 开启 | ✅ 开启 |
| `Warning` | 非致命异常或降级处理（如某楼层无构件、对齐点不足、剖切线未穿过任何实体） | ✅ 开启 | ✅ 开启 |
| `Error` | 错误与异常（配置文件损坏、转换失败、未处理异常） | ✅ 开启 | ✅ 开启 |
| `Critical` | 严重崩溃（极少使用） | ✅ 开启 | ✅ 开启 |

### 3. 日志输出目标配置切换

采用 **配置文件驱动** 的动态切换方案。

#### 3.1 配置文件结构（`appsettings.json`）

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "MetroToolKits.SectionGenerator.Core": "Warning"
    },
    "Outputs": {
      "Console": { "Enabled": false },
      "File": {
        "Enabled": true,
        "Path": "logs/MetroToolKits.log",
        "MaxFileSizeMB": 10
      },
      "AcadCommandLine": {
        "Enabled": true,
        "MinLevel": "Warning"
      }
    }
  },
  "DeveloperMode": false
}
```

#### 3.2 开发覆盖配置（`appsettings.Development.json`）

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Debug"
    },
    "Outputs": {
      "Console": { "Enabled": true },
      "AcadCommandLine": { "MinLevel": "Information" }
    }
  },
  "DeveloperMode": true
}
```

#### 3.3 环境切换方式

| 环境 | 设置方式 | 生效配置 |
|:---|:---|:---|
| 开发 | 设置环境变量 `DOTNET_ENVIRONMENT=Development` | `appsettings.Development.json` 覆盖 |
| 测试 | 设置 `DOTNET_ENVIRONMENT=Staging` | `appsettings.Staging.json` |
| 生产 | 不设置变量或设为 `Production` | 仅 `appsettings.json` |

### 4. 实施步骤

1. **引入依赖**  
   在 `Bootstrap` 项目中添加 `Microsoft.Extensions.Configuration.Json` 和 `Microsoft.Extensions.Logging.Configuration`。

2. **创建配置文件**  
   在 `Bootstrap` 输出目录放置 `appsettings.json` 和 `appsettings.Development.json`。

3. **修改 Startup 日志构建逻辑**  
   使用 `ConfigurationBuilder` 加载 JSON，调用 `AddConfiguration` 将日志配置绑定到 `ILoggingBuilder`。

4. **自定义 Provider 适配配置**  
   为 `AcadEditorLoggerProvider` 增加 `MinLevel` 参数，根据配置动态过滤。

5. **业务代码零改动**  
   所有层继续使用 `ILogger<T>` 接口记录，无需关心输出目标。

---

### 5. 性能注意事项

- **高频 Trace 日志**：在构件遍历循环中，使用 `if (_logger.IsEnabled(LogLevel.Trace))` 包裹，避免不必要的字符串拼接。
- **文件日志滚动**：通过第三方库（如 Serilog）实现文件大小限制和自动归档。
- **命令行输出限流**：`Editor.WriteMessage` 每帧调用有开销，可对同一秒内的多条日志合并输出。
