## 3. 已实现命令

| 命令 | 说明 |
|:---|:---|
| `GenSection` | 选择剖切线 → 输入深度 → 指定插入点 → 生成多楼层剖面块 |
| `FloorConfig` | 打开楼层配置管理窗口（增删改楼层、拾取对齐点） |
| `CheckSectionUpdates` | 打开变更检测对话框（非模态），扫描所有剖面块 |
| `UpdateSection` | 选择单个剖面块立即重新生成并替换 |
| `ConvertRegion` | 区域引导转换（框选 → 逐层分配构件类型） |
| `RevertConversion` | 恢复构件转换（从 XData 备份还原） |
| `LayerMapping` | 打开全图图层映射管理器 |

## 5. 日志系统

- **开发日志**：`ILogger<T>` 注入，输出到 AutoCAD 命令行（Warning+）和 JSON 文件（Information+）
- **用户日志**：`UserLogger` 单例，命令行提示 + `MetroToolKits_User.log` JSON 文件
- **配置切换**：`appsettings.json`（生产）/ `appsettings.Development.json`（开发，Debug/Trace 全开）
- **环境变量**：`DOTNET_ENVIRONMENT=Development` 切换开发模式
