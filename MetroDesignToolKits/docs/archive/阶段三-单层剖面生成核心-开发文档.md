# 阶段三：单层剖面生成核心 - 开发文档

**版本**: v1.0  
**日期**: 2026-04-16  
**状态**: ✅ 已完成

---

## 1. 概述

阶段三实现了从平面构件到剖面几何数据的核心算法，并能绘制为 AutoCAD 块。用户可选择剖切线、输入视图深度，系统自动识别构件、计算剖面、绘制块并附加标注。

---

## 2. 架构设计

### 2.1 分层职责

```
Plugin 层（Commands）
    ↓ 调用
App 层（UseCases）
    ↓ 调用
Core 层（SectionComposer）← 纯算法，不依赖 AutoCAD
    ↓ 使用
Foundation.Building（Wall/Slab/Column）
    ↓ 基于
Foundation.Core（Point3D/Line3D/Transform3D）
```

### 2.2 数据流

```
用户选择剖切线
    ↓
GenSectionCommand 获取参数（剖切线、深度、插入点）
    ↓
GenerateSectionUseCase 编排流程
    ├─ IFloorConfigRepository 读取楼层配置
    ├─ IElementRecognizer 识别构件（基于 MK_ 图层）
    ├─ SectionComposer 计算剖面几何
    └─ IDrawingService 绘制块 + 标注 + XData
```

## 3. 核心类详解

### 3.1 `SectionGeometryData` — 剖面几何数据模型

**位置**: `Core/Sections/SectionGeometryData.cs`

**职责**: 存储单层剖面的所有几何信息（剖切线 + 看线 + 楼板线）

**关键字段**:
- `FloorName`: 楼层名称（如 "F1"）
- `BaseElevation`: 楼层底部绝对标高
- `Elements`: 各构件的剖面数据（`ElementSectionData` 列表）
- `SlabLines`: 楼板剖面线（顶板/底板的 6 条线）
- `AllCutLines`: 所有剖切线（构件 + 楼板）
- `AllSightLines`: 所有看线（投影线）

**设计要点**:
- 不可变对象（`init` 属性）
- 区分剖切线（被剖到的截面）和看线（后方可见线）
- 为阶段五变更检测预留 `SourceHandle`

---

### 3.2 `SectionComposer` — 剖面组合器（核心算法）

**位置**: `Core/Sections/SectionComposer.cs`

**职责**: 接收剖切线 + 构件列表，计算并返回 `SectionGeometryData`

**核心方法**:

```csharp
public SectionGeometryData Generate(
    Line3D sectionLine,
    Vector3D viewDirection,
    IEnumerable<BuildingElement> elements,
    FloorConfig floorConfig,
    double baseElevation = 0)
```

**算法流程**:
1. 遍历构件，调用 `element.GetSectionGeometry(sectionLine, viewDirection)`
2. 过滤空结果（不与剖切线相交的构件）
3. 生成楼板线（顶板/底板，含坡度处理）
4. 组装为 `SectionGeometryData`

**坡度处理逻辑**:
```csharp
if (config.HasSlope && config.SlopeValue > 0)
{
    double length = sectionLine.Length;
    double slopeDelta = length * config.SlopeValue;
    // 顶板终点 Z += slopeDelta
}
```

---

### 3.3 `FloorGeometryHasher` — 楼层几何指纹

**位置**: `Core/Sections/FloorGeometryHasher.cs`

**职责**: 计算构件列表的 SHA256 哈希，用于变更检测（阶段五）

**算法**:
1. 按 `SourceHandle` 排序构件（保证确定性）
2. 对每个构件提取关键几何参数（坐标、尺寸）
3. 拼接字符串 → SHA256 → 取前 16 位十六进制

**示例输出**: `"a3f5c8d2e1b4f6a9"`

---

### 3.4 `GenerateSectionUseCase` — 剖面生成用例

**位置**: `App/UseCases/GenerateSectionUseCase.cs`

**职责**: 编排剖面生成的完整流程（应用层）

**依赖注入**:
- `IFloorConfigRepository`: 读取楼层配置
- `IElementRecognizer`: 识别构件
- `SectionComposer`: 计算剖面几何
- `IDrawingService`: 绘制块

**执行流程**:
```csharp
1. 加载楼层配置（从 JSON 或使用默认值）
2. 构建剖切线（Line3D）
3. 计算视图方向（剖切线方向旋转 90°）
4. 识别构件（调用 IElementRecognizer）
5. 计算剖面几何（调用 SectionComposer）
6. 绘制块（调用 IDrawingService）
7. 返回结果（含块名称）
```

---

### 3.5 `LayerBasedElementRecognizer` — 基于图层的构件识别器

**位置**: `Infrastructure/Recognition/LayerBasedElementRecognizer.cs`

**职责**: 扫描模型空间中 `MK_` 前缀图层的实体，转换为 `BuildingElement`

**图层映射规则**:
```csharp
"MK_结构墙" → Wall
"MK_结构柱" → Column
"MK_楼板"   → Slab
```

**转换逻辑**:
- `Line` → `Wall`（起终点、高度 3000、厚度 200）
- `Circle` → `Column`（中心点、直径 = 半径×2）
- `Polyline` → `Slab`（轮廓点、厚度 200）

**限制**: 当前版本使用硬编码默认值（高度/厚度），阶段四将支持从属性读取。

---

### 3.6 `CadDrawingService` — AutoCAD 绘图服务

**位置**: `CadAdapter/CadDrawingService.cs`

**职责**: 将 `SectionGeometryData` 绘制为 AutoCAD 块并插入图纸

**绘制内容**:
1. **剖切线**（粗实线，LineWeight.050，图层 `MK_剖切线`）
2. **看线**（细实线，LineWeight.025，图层 `MK_看线`）
3. **层高标注**（AlignedDimension，偏移 -800mm）
4. **标高文字**（底板 "±0.000"，顶板 "+5.800"）
5. **坡度标注**（文字，"i=0.2%"）
6. **XData 快照**（存储楼层名 + 生成时间，供阶段五变更检测）

**块命名规则**: `MK_剖面_{楼层名}_{时间戳}`  
**示例**: `MK_剖面_F1_20260416T143022`

---

### 3.7 `GenSectionCommand` — 生成剖面命令

**位置**: `Plugin/Commands/GenSectionCommand.cs`

**命令名**: `GenSection`

**交互流程**:
```
1. 提示：选择剖切线（直线）
2. 提示：视图深度（看线深度，mm）<3000>
3. 提示：指定剖面图插入点
4. 执行：调用 IGenerateSectionUseCase
5. 反馈：剖面已生成，块名称：MK_剖面_F1_...
```

## 4. 配置文件

### 4.1 `SectionGeneratorConfig.json` — 楼层配置

**位置**: `Plugin/Resources/SectionGeneratorConfig.json`（运行时复制到输出目录）

**结构**:
```json
{
  "GlobalSlopeEnabled": true,
  "GlobalSlopeValue": 0.002,
  "GlobalSlopeTarget": "StructuralSlab",
  "Floors": [
    {
      "Name": "F1",
      "Height": 5200.0,
      "FinishThickness": 120.0,
      "BottomSlabThickness": 800.0,
      "TopSlabThickness": 600.0,
      "HasSlope": true,
      "SlopeValue": 0.002,
      "SlopeTarget": "StructuralSlab",
      "AlignmentSourcePoints": [],
      "AlignmentTargetPoints": []
    }
  ]
}
```

**字段说明**:
- `Height`: 层高（mm）
- `BottomSlabThickness`: 底板厚度（mm）
- `TopSlabThickness`: 顶板厚度（mm）
- `FinishThickness`: 装修面层厚度（mm）
- `HasSlope`: 是否有坡度
- `SlopeValue`: 坡度值（0.002 = 千分之二 = 0.2%）
- `SlopeTarget`: 坡度目标（"StructuralSlab" 结构找坡 / "FinishLayer" 面层找坡）

## 6. 已知限制与后续改进

### 6.1 当前限制

1. **仅支持单层**: 多楼层堆叠在阶段四实现
2. **硬编码默认值**: 构件高度/厚度使用固定值（3000/200），未从属性读取
3. **简化剖切算法**: 仅支持正交剖切，斜交剖切精度待优化
4. **无看线遮挡**: 看线计算在阶段六实现
5. **标注位置固定**: 标注偏移量硬编码，未提供配置

## 8. 使用示例

### 8.1 在 AutoCAD 中使用

```
1. NETLOAD 加载 MetroToolKits.Bootstrap.dll
2. 绘制一条直线作为剖切线
3. 使用 ConvertRegion 或 LayerMapping 将图元转换为 MK_ 图层
4. 运行命令：GenSection
5. 选择剖切线
6. 输入视图深度（默认 3000）
7. 指定插入点
8. 剖面块自动生成
```

### 8.2 代码示例

```csharp
// 手动调用用例
var useCase = serviceProvider.GetService<IGenerateSectionUseCase>();
var result = useCase.Execute(new GenerateSectionRequest
{
    CutLineStart   = new Point3D(0, 0, 0),
    CutLineEnd     = new Point3D(6000, 0, 0),
    ViewDepth      = 3000,
    InsertionPoint = new Point3D(10000, 0, 0)
});

if (result.Success)
    Console.WriteLine($"块名称：{result.BlockName}");
```

## 10. 性能考虑

### 10.1 当前性能

- **构件识别**: O(n)，n = 模型空间实体数量
- **剖切计算**: O(m)，m = 构件数量
- **绘图**: O(k)，k = 剖切线数量

### 10.2 优化方向（后续）

- 空间索引（R-Tree）加速构件查询
- 剖切线缓存（相同剖切线复用结果）
- 批量绘制（减少事务次数）

## 11. 故障排查

### 11.1 常见问题

**Q: 运行 GenSection 提示"无活动文档"**  
A: 确保在 AutoCAD 中打开了图纸

**Q: 生成的剖面块为空**  
A: 检查是否有 MK_ 前缀图层，运行 `ConvertRegion` 或 `LayerMapping` 转换构件

**Q: 剖切线未穿过构件**  
A: 确保剖切线与构件相交，可用 `LIST` 命令查看坐标

**Q: 坡度未生效**  
A: 检查 `SectionGeneratorConfig.json` 中 `HasSlope` 和 `SlopeValue` 配置

### 11.2 调试技巧
