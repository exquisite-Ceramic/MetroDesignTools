## 1. 概述

阶段四在阶段三单层剖面的基础上，实现了多楼层配置管理、三点对齐变换和垂直堆叠生成。用户可通过 `FloorConfig` 命令管理任意数量的楼层，配置层高、板厚、坡度及对齐点，系统自动将各层剖面按标高累加堆叠为完整的多层剖面块。

### 2.2 数据流（多楼层）

```
FloorConfig 命令 → FloorConfigWindow（增删改楼层、拾取对齐点）
                                    ↓ 保存
                        JsonFloorConfigRepository（JSON 文件）
                                    ↓ 读取

    ├─ 逐层调用 IElementRecognizer 识别构件

    └─ CadDrawingService.DrawMultiFloorSectionBlock()
        ├─ 绘制各层剖切线 + 看线
        ├─ 绘制楼层标注（层高标注 + 标高文字 + 坡度）
        └─ 附加 XData 快照（楼层名列表 + 总高度）
```

## 3. 核心类详解

### 3.1 `MultiFloorSectionComposer` — 多楼层堆叠算法

**位置**: `Core/Sections/MultiFloorSectionComposer.cs`

**核心方法**:
```csharp
public MultiFloorSectionData Generate(
    Line3D sectionLine,
    Vector3D viewDirection,
    IReadOnlyDictionary<string, IReadOnlyList<BuildingElement>> floorElements,
    IReadOnlyList<FloorConfig> floors)
```

**堆叠算法**:
```
cumulativeElevation = 0
foreach floor in floors:
    1. 应用三点对齐变换（若有）→ alignedSectionLine
    2. SectionComposer.Generate(alignedSectionLine, ..., baseElevation=cumulativeElevation)
    3. cumulativeElevation += floor.BottomSlabThickness + floor.Height + floor.TopSlabThickness
```

**标高累加规则**:
- 每层的 `baseElevation` = 前所有层的（底板厚 + 层高 + 顶板厚）之和
- 示例：F1(800+3000+600=4400) → F2.baseElevation=4400 → F2(1000+4000+700=5700) → F3.baseElevation=10100

### 3.2 `MultiFloorSectionData` — 多楼层剖面数据

**字段**:
- `Floors`: 各楼层 `SectionGeometryData` 列表（按楼层顺序）
- `TotalHeight`: 总高度（所有楼层累加）
- `AllCutLines`: 所有楼层剖切线（合并）
- `AllSightLines`: 所有楼层看线（合并）

### 3.3 `FloorConfigWindow` — 楼层配置管理窗口

**功能**:
- 左侧楼层列表：增删改楼层、上下移动顺序
- 右侧参数编辑：层高、底板厚、顶板厚、装修面层、坡度
- 对齐点拾取：点击"拾取对齐点"关闭窗口，在 CAD 中依次拾取 6 个点（源3+目标3）
- 全局坡度设置：统一控制所有楼层的坡度方向和目标

**对齐点拾取流程**:
```
1. 点击"拾取对齐点..." → 窗口关闭，进入 CAD 交互
2. 在平面图中拾取 3 点（原点、X方向点、Y方向点）
3. 在剖面图中拾取对应 3 点
4. 自动重新打开配置窗口，显示"已设置（3点）"
5. 点击"保存"写入 JSON
```

### 3.4 `CadDrawingService` — 多楼层绘制

**多楼层标注内容**:
- 每层层高标注（AlignedDimension，偏移 -800mm）
- 每层楼层名称文字（偏移 -600mm）
- 每层底板标高文字（±0.000 / +4.400 等）
- 每层坡度标注（i=0.2%，仅有坡度时）
- 多层时额外绘制总高度标注（偏移 -900mm）

**XData 快照格式**（应用名 `MK_SectionSnapshot`）:
```
[AppName] MK_SectionSnapshot
[String]  "F1,F2,F3"          ← 楼层名列表
[String]  "2026-04-16T14:30"  ← 生成时间
[Real]    10100.0              ← 总高度
```

### 3.5 `GenerateSectionUseCase` — 多楼层用例

**变化**:
- 注入 `MultiFloorSectionComposer`
- 从 `IFloorConfigRepository` 加载所有楼层配置
- 逐层调用 `IElementRecognizer`（当前实现：所有层使用同一识别结果）
- 调用 `DrawMultiFloorSectionBlock` 替代单层方法

## 8. 已知限制

1. **构件识别未区分楼层**：当前所有楼层使用同一识别结果（扫描整个模型空间），阶段五将支持按楼层过滤
2. **对齐点仅支持平移+旋转**：`Transform3D.AlignPoints` 不支持缩放，若平面图与剖面图比例不同需手动调整
3. **标注位置固定**：层高标注偏移量硬编码，未提供配置
