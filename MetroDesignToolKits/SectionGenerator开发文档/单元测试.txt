## 单元测试范围规划

依据架构原则——**Core 层不依赖 AutoCAD API 和外部框架，可脱离 CAD 环境独立测试**——单元测试应覆盖所有纯算法、数据模型、业务规则的类。基础设施层和表示层因强依赖 AutoCAD 或文件系统，采用集成测试或手动验证。

---

### 一、需要编写单元测试的模块

| 项目 | 测试类/模块 | 测试内容 | 优先级 |
|:---|:---|:---|:---|
| **Foundation.Core** | `Point3D`, `Line3D`, `Polygon3D` | 几何运算：距离、交点、包含判断、变换 | 🔴 高 |
| | `Transform3D` | 三点对齐变换矩阵计算；平移、旋转、缩放组合 | 🔴 高 |
| | `MathUtils` | 向量运算、插值、角度转换 | 🟡 中 |
| **Foundation.Building** | `ElementTypeDefinition` 加载器 | JSON 反序列化正确性；默认值填充 | 🟡 中 |
| | `BuildingElement` 属性访问 | 动态属性读写；几何哈希生成（使用模拟数据） | 🔴 高 |
| | `Wall.GetSectionGeometry()` | 不同剖切线位置（正交、斜交）的剖切面域计算 | 🔴 高 |
| | `Slab.GetSectionGeometry()` | 平楼板、带坡度楼板的剖切轮廓；结构找坡 vs 面层找坡 | 🔴 高 |

| **SectionGenerator.Core** | `SectionComposer` | 单层构件聚合为剖面数据；多构件重叠时的合并逻辑 | 🔴 高 |

| | `FloorGeometryHasher` | 相同构件列表产生相同哈希；构件增删改导致哈希变化 | 🔴 高 |

---

### 二、不需要单元测试（或采用集成测试）的模块

| 项目 | 原因 | 验证方式 |
|:---|:---|:---|
| **Foundation.Cad** | 所有方法依赖 AutoCAD 运行时 API | 手动编写临时命令在 CAD 内验证 |
| **SectionGenerator.Infrastructure** | 涉及文件读写（JSON）、图纸扩展字典操作 | 集成测试：在 CAD 中运行，检查文件生成与读取 |
| **SectionGenerator.Plugin** | UI 交互、命令响应逻辑 | 手动测试或自动化 UI 测试（成本高，暂不要求） |
| **SectionGenerator.App** | 用例编排，依赖多个接口具体实现 | 使用 Mock 对象进行单元测试（可选），但初期可随集成测试验证 |

### 三、关键单元测试用例示例

#### 1. `Transform3D.FromThreePointAlignment`

```csharp
[Fact]
public void ThreePointAlignment_Identity_ReturnsIdentityMatrix()
{
    var src = new[] { new Point3D(0,0,0), new Point3D(1,0,0), new Point3D(0,1,0) };
    var tgt = new[] { new Point3D(0,0,0), new Point3D(1,0,0), new Point3D(0,1,0) };
    var transform = Transform3D.FromThreePointAlignment(src, tgt);
    
    var result = transform.Transform(new Point3D(2,3,0));
    Assert.Equal(new Point3D(2,3,0), result);
}

[Fact]
public void ThreePointAlignment_TranslationOnly()
{
    var src = new[] { new Point3D(0,0,0), new Point3D(1,0,0), new Point3D(0,1,0) };
    var tgt = new[] { new Point3D(5,5,0), new Point3D(6,5,0), new Point3D(5,6,0) };
    var transform = Transform3D.FromThreePointAlignment(src, tgt);
    
    var result = transform.Transform(new Point3D(2,3,0));
    Assert.Equal(new Point3D(7,8,0), result);
}
```

#### 2. `Wall.GetSectionGeometry` 正交剖切

```csharp
[Fact]
public void Wall_OrthogonalSection_ReturnsCorrectPolygon()
{
    // 墙体：起点(0,0)，终点(0,5000)，高度3000，厚度200
    var wall = new Wall
    {
        StartPoint = new Point3D(0, 0, 0),
        EndPoint = new Point3D(0, 5000, 0),
        Height = 3000,
        Thickness = 200
    };
    
    // 剖切线：X=100 的垂直线（从左向右剖视）
    var sectionLine = new Line3D(new Point3D(100, -1000, 0), new Point3D(100, 6000, 0));
    
    var result = wall.GetSectionGeometry(sectionLine);
    
    // 期望剖切面域为矩形：宽度=墙厚200，高度=3000
    Assert.NotNull(result.SectionPolygon);
    Assert.Equal(200, result.SectionPolygon.Bounds.Width, 1e-6);
    Assert.Equal(3000, result.SectionPolygon.Bounds.Height, 1e-6);
}
```

#### 3. `FloorGeometryHasher` 变化检测

```csharp
[Fact]
public void GeometryHash_ChangesWhenElementMoved()
{
    var elements = new List<BuildingElement>
    {
        new Wall { StartPoint = new Point3D(0,0,0), EndPoint = new Point3D(0,5000,0), Height = 3000, Thickness = 200 }
    };
    var hasher = new FloorGeometryHasher();
    var hash1 = hasher.ComputeHash(elements);
    
    // 移动墙体
    elements[0].StartPoint = new Point3D(100, 0, 0);
    elements[0].EndPoint = new Point3D(100, 5000, 0);
    var hash2 = hasher.ComputeHash(elements);
    
    Assert.NotEqual(hash1, hash2);
}

[Fact]
public void GeometryHash_SameGeometry_ProducesSameHash()
{
    var elements1 = new List<BuildingElement> { /* 构造 */ };
    var elements2 = new List<BuildingElement> { /* 相同几何数据，但不同对象 */ };
    var hasher = new FloorGeometryHasher();
    
    Assert.Equal(hasher.ComputeHash(elements1), hasher.ComputeHash(elements2));
}
```

#### 4. `Slab` 坡度计算

```csharp
[Fact]
public void Slab_WithStructuralSlope_AdjustsTopAndBottom()
{
    var slab = new Slab
    {
        Boundary = new Polygon3D(/* 矩形 */),
        Thickness = 200,
        HasSlope = true,
        SlopeValue = 0.02,  // 2% 坡度
        SlopeTarget = SlopeTarget.StructuralSlab
    };
    var sectionLine = new Line3D(/* 沿坡度方向剖切 */);
    
    var result = slab.GetSectionGeometry(sectionLine);
    
    // 验证顶面、底面坐标有高差
    var topLeft = result.SectionPolygon.Vertices[0];
    var topRight = result.SectionPolygon.Vertices[1];
    Assert.NotEqual(topLeft.Z, topRight.Z);
}
```

### 四、测试框架与工具

- **测试框架**：xUnit（与 .NET 8 集成良好）
- **断言库**：FluentAssertions（可读性强）
- **Mock 库**：NSubstitute 或 Moq（用于应用层接口 Mock）
- **测试运行**：Visual Studio Test Explorer 或 `dotnet test`

---

### 五、测试覆盖率目标

| 层级 | 目标覆盖率 | 说明 |
|:---|:---|:---|
| **Foundation.Core** | ≥ 90% | 基础几何运算，要求高可靠性 |
| **Foundation.Building** | ≥ 80% | 构件核心算法 |
| **SectionGenerator.Core** | ≥ 80% | 剖面组合与指纹计算 |
| **其他层** | 不作硬性要求 | 依赖外部环境，集成测试覆盖 |

---

### 六、集成测试补充（手动执行清单）

1. **构件转换流程**：全图映射、区域引导、备份恢复。
2. **多楼层对齐**：拾取三点后剖面垂直对齐验证。
3. **变更检测**：修改平面后运行检测命令，对话框状态正确。
4. **双向定位**：平面→剖面、剖面→平面跳转。
5. **配置文件读写**：修改 JSON 后重启命令，参数生效。

---

按此范围编写单元测试，可确保核心算法在脱离 CAD 环境下的正确性和稳定性，并为后续重构提供安全网。
